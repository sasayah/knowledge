# 哲学学習ロードマップ（多年計画）

> 対象: hiromu / 開始: 2026-06-15（月）想定 / 1日30〜45分 / 何年も続ける前提
> ロールモデル: **東浩紀**（ゲンロン）×**中島聡**（週刊 Life is beautiful）——思想の深さ × エンジニアの一次知識で技術を語る力
> 書籍・リソースはすべて 2026-06-10 時点で実在・入手可否・現状をWeb検索で確認済み（詳細は `curriculum/books.md`）

---

## 0. 設計思想（最初に読む）

1. **「地図 → 拡大」方式。** まず数週間で哲学史2500年の全体像（地図）を手に入れ、以後はその地図の一部を順に拡大していく。どの本を読んでいても「いま自分は地図のどこにいるか」を言えることが、挫折しない最大のコツ。
2. **適用とアウトプットはDay 1から。** 「カリキュラムを終えてから語る」のではない。初日から (a) 毎日のノート、(b) 週1の「ニュース×概念」ノート、(c) 週1の「3分で語る」練習を回す。東浩紀的な「批評」は知識の量ではなく、概念をいま起きていることに接続する運動神経で決まる。
3. **原典は「触れる」、入門書で「理解する」。** 原典完読主義は取らない。薄い新訳（『ソクラテスの弁明』『方法序説』等）だけ通読し、大著（『純粋理性批判』等）は入門書＋『100分de名著』で構造を掴む。
4. **東浩紀は最後ではなく「目的地」として最初から見えている。** Phase 4で本格的に読むが、『弱いつながり』『訂正する力』は語り口が平易なので、息抜きとしていつ前倒しで読んでもよい。彼の議論はデリダ（20世紀思想）の上に建っているため、Phase 3を経ると解像度が一気に上がる——その「二度読み」も体験として面白い。
5. **スタイルモデルは中島聡。** 思想の系譜は東浩紀から学ぶが、「語り方」のお手本は中島聡のメルマガ「週刊 Life is beautiful」——**技術の中身を一次知識で正確に解説した上で、自分の意見と予測を言う**スタイル。哲学レンズ×エンジニア解説のハイブリッド時評（`method/training.md` §5の型D）がこのカリキュラムのアウトプットの目標形。エンジニアであることはハンデではなく、東浩紀にも職業哲学者にもない武器である。

### 1日の基本リズム（30〜45分）

| 時間 | やること |
|---|---|
| 20〜25分 | 読書。**新書・入門書は1日10〜20頁、原典は1日5〜10頁**（週あたり新書60〜100頁／原典30〜50頁） |
| 10〜15分 | ノート＋Claude Codeとの対話。今日の範囲を「自分の言葉で3行」＋疑問1つをAIにぶつける |
| （枠外） | 通勤・家事などの「ながら時間」にコテンラジオ／ゆる哲学ラジオ。これは45分に数えない |

### 週の基本リズム

- **月〜金**: 上記の日課
- **土**: 週次レビュー（30〜45分）= 今週の概念の整理＋「ニュース×概念」ノート1本＋「3分で語る」練習（Claudeに向かって口頭またはテキストで説明→添削してもらう）
- **日**: 予備日。遅れの回収 or 完全休養。**休んでも巻き戻さない**

### アウトプットの段階的拡大（媒体）

| 時期 | 媒体 |
|---|---|
| Day 1〜 | このリポジトリのノート（`daily/`） |
| Week 3〜 | 週次エッセイの下書き（`essays/drafts/`。公開はしなくてよい） |
| Week 4〜 | X投稿（月2回目安、手応えのある回だけ。週次エッセイを140〜500字に圧縮） |
| Phase 1終了〜 | ブログ/note 月1本（800〜2000字） |
| Phase 3〜 | 人と話す: 読書会参加、シラスのコメント欄、ゲンロンカフェ現地（行ければ） |

### 挫折保険（重要）

- 2週間止まったら、止まった本は**いったん捨てて**現Phaseの一番易しい本から再開してよい
- 原典・難所は「2割理解で前進」を公式ルールとする。Phase 5で必ず戻ってくる
- 進捗管理はClaude Codeに任せる（後述のスラッシュコマンド）

## 2. 各Phase詳細

### Phase 0「地図を手に入れる」（4週間）

- **目的**: 西洋哲学2500年を「真理・国家・神・存在」の4つの問いの歴史として一望する。固有名詞アレルギーを消す。学習習慣とアウトプット習慣を確立する。
- **読む本**: 飲茶『史上最強の哲学入門』（河出文庫、352頁＝1日約13頁）。参照書として出口治明『哲学と宗教全史』を手元に置き、気になった人物だけ辞書的に引く（通読しない）。
- **音声**: ゆる哲学ラジオを「読んだ哲学者の回」だけつまみ聴き。コテンラジオで歴史感覚の地ならし（ながら時間）。
- **週次詳細**: `curriculum/first-8-weeks.md` 参照。
- **終了時に語れること（マイルストーン）**:
  - [ ] 「哲学って何をする学問？」に自分の言葉で2分で答えられる
  - [ ] 真理・国家・神・存在の4テーマそれぞれで哲学者を3人ずつ挙げ、論争の流れを一筆書きできる
  - [ ] 「哲学史の地図」を1枚のMarkdown（または図）に自作してある
  - [ ] X投稿を最低1本出している

### Phase 1「古代ギリシャ——哲学の誕生」（約2.5ヶ月）

- **目的**: 哲学の「型」（問答、定義、根拠を問う）が生まれた現場を見る。初めての原典通読を達成する。中世は同じ本で軽く通過する。
- **読む本**（順に）:
  1. 斎藤哲也編『哲学史入門I 古代ギリシアからルネサンスまで』（NHK出版新書）——千葉雅也・納富信留らへのインタビュー形式で読みやすい
  2. プラトン『ソクラテスの弁明』（光文社古典新訳文庫、納富信留訳）——**初の原典**。訳者がそのまま『哲学史入門I』の語り手の一人なので接続が良い
  3. 参照: 出口治明の該当章、『100分de名著』バックナンバーの古代ギリシャ関連回（電子版テキストが入手可）
- **ペース**: 新書は1日10〜15頁、『弁明』は1日5〜8頁の精読。
- **終了時に語れること**:
  - [ ] ソクラテスが「何の罪で」死刑になり「なぜ逃げなかったか」を3分で話せる
  - [ ] 無知の知（不知の自覚）・問答法・イデア論・四原因説を、EC/AIの実例に1つずつ翻訳できる（例: イデア論→データモデルと現実の商品の関係）
  - [ ] 「ソフィストとソクラテスの違い」を現代のインフルエンサー/論破文化に重ねて説明できる
  - [ ] ブログ/note記事 第1号「AI時代にソクラテスを読む」（仮）を公開している

### Phase 2「近代——理性の時代とその動揺」（約5ヶ月）

- **目的**: 「近代的な考え方」（主体・理性・科学・進歩）がどう組み立てられ、ニーチェでどう壊れ始めたかを掴む。ここが20世紀思想と東浩紀を理解するための土台。
- **読む本**（順に）:
  1. 木田元『反哲学入門』（新潮文庫）——「西洋哲学」という営みそのものを相対化する第二の地図。近代に入る前に読むと視界が開ける
  2. デカルト『方法序説』（岩波文庫、谷川多佳子訳）——**2冊目の原典**。本文は薄く、1ヶ月で通読可能
  3. 石川文康『カント入門』（ちくま新書）——「血の通ったカント」。難所なので1日10頁でゆっくり
  4. 『哲学史入門II』（NHK出版新書、近代篇）——デカルト〜カント〜ヘーゲルを俯瞰で再整理
  5. 竹田青嗣『ニーチェ入門』（ちくま新書）＋ニーチェ『ツァラトゥストラ』上（光文社古典新訳文庫、丘沢静也訳）を**つまみ読み**（「触れる」担当。完読不要）
- **音声**: 『100分de名著』2026年2月放送の集中講義「三大哲学書」（戸谷洋志、カント『純粋理性批判』／ヘーゲル『精神現象学』／ハイデガー『存在と時間』）のテキストをカント学習の補助線に使う（ハイデガー部分はPhase 3で再利用）。
- **終了時に語れること**:
  - [ ] 「我思う、ゆえに我あり」が何を疑った末の結論かを2分で話せる
  - [ ] カントのコペルニクス的転回を「人間は世界をありのままに見ていない」という話としてLLMの知覚・表現の限界に重ねられる
  - [ ] ルサンチマン・ニヒリズム・永遠回帰を使ってSNS論・キャンセルカルチャー論が1本書ける
  - [ ] 「近代とは何だったか」を5分で話せる（→これがポストモダン理解の前提）

### Phase 3「20世紀——現象学・構造主義・ポスト構造主義」（約6ヶ月）

- **目的**: 東浩紀の直接の足場である20世紀思想を通過する。「主体の解体」「構造」「差異」「脱構築」を道具として使えるようにする。
- **読む本**（順に）:
  1. 谷徹『これが現象学だ』（講談社現代新書）——フッサール。著者は『哲学史入門III』の語り手でもある
  2. 内田樹『寝ながら学べる構造主義』（文春新書）——ソシュール、レヴィ＝ストロース、バルト、ラカン、フーコーを最速で
  3. 千葉雅也『現代思想入門』（講談社現代新書、新書大賞2023大賞）——**このPhaseの主著**。デリダ・ドゥルーズ・フーコーを「二項対立の脱構築」として読む。東浩紀理解の直前準備として最適
  4. 『哲学史入門III 現象学・分析哲学から現代思想まで』（NHK出版新書）——分析哲学・フランクフルト学派も含め20世紀の見取り図を完成させる
  5. 選択: 國分功一郎『暇と退屈の倫理学』（新潮文庫）——ハイデガー×消費社会論の応用例。余裕がなければPhase 5へ
- **音声**: ゆる哲学ラジオのハイデガー・ウィトゲンシュタイン回。『100分de名著』2026年4月のウィトゲンシュタイン回（『論理哲学論考』『哲学探究』）テキスト。
- **終了時に語れること**:
  - [ ] 「構造主義は何に対するNOだったか」を3分で話せる
  - [ ] 脱構築を「二項対立のどちらかに与せず、対立の前提を崩す」操作として説明し、実務の議論（例:「人間 vs AI」「個人最適 vs 全体最適」）に1回使ってみせられる
  - [ ] 『現代思想入門』を未読の同僚に10分でプレゼンできる
  - [ ] フーコーの規律権力／生権力でレコメンドシステム・スコアリング社会を論じる記事が1本書ける

### Phase 4「東浩紀と情報社会の思想」（約8ヶ月）

- **目的**: ロールモデルの主要著作を刊行順ではなく難易度順に縦走し、「誤配」「観光客」「訂正可能性」を自分の語彙にする。同時に、ゲンロン/シラスという「批評の現場」の観客になる。
- **読む本**（順に）:
  1. 『弱いつながり 検索ワードを探す旅』（幻冬舎文庫）——最も平易。ネット時代の身体論
  2. 『動物化するポストモダン』（講談社現代新書、2001）——データベース消費。EC×AIの人間には即戦力の概念
  3. 『ゲンロン戦記』（中公新書ラクレ）——思想を「経営」する話。スタートアップで働く読者には別格に刺さる
  4. 『一般意志2.0』（講談社文庫）——ルソー×Google。アルゴリズムと民主主義
  5. 『観光客の哲学 増補版』（ゲンロン、2023）——主著。原版は毎日出版文化賞受賞
  6. 『訂正可能性の哲学』（ゲンロン、2023）——現時点の理論的到達点。ウィトゲンシュタイン・クリプキを使うのでPhase 3の貯金が効く
  7. 『訂正する力』（朝日新書）——6の実践・応用編。語り下ろしで速く読める
- **映像**: **シラス「ゲンロン完全中継チャンネル」の購読をこのPhaseで開始**（月額制、単品購入も可）。番組は長時間（数時間級）なので「月1〜2本を、1日30分ずつ分割視聴」が現実的。視聴後に論点ノートを1本書く。
- **終了時に語れること**:
  - [ ] 「データベース消費」で自社プロダクト/推薦システムのユーザー行動を分析した文章が書ける
  - [ ] 「誤配」と「弱いつながり」を使って、レコメンドのフィルターバブル問題に対する設計上の提案が語れる
  - [ ] 「訂正可能性」をアジャイル開発・LLMのアラインメント・コミュニティ運営に接続して30分話せる
  - [ ] 東浩紀の議論への**反論**を最低1つ、自分の言葉で持っている（信者にならないこと）

### Phase 5「技術哲学と自分の思想」（常設・2028-05〜）

- **目的**: 「東浩紀＋もっと技術」の「もっと技術」を埋め、自分の問い（EC・AI・事業の現場から出てくる問い）を哲学の言葉で立てられるようになる。読む→書く・議論するへ重心を移す。
- **読む本**（順不同、関心駆動で）:
  - 鈴木健『なめらかな社会とその敵』（ちくま学芸文庫）——PICSY・分人民主主義。エンジニアが書いた社会哲学の金字塔
  - 戸谷洋志『未来倫理』（集英社新書）／『スマートな悪』（講談社）——テクノロジー倫理の現役世代
  - ユク・ホイ『中国における技術への問い』（ゲンロン）——技術哲学の世界的最前線。難度高
  - ハイデガー『技術とは何だろうか 三つの講演』（講談社学術文庫、森一郎訳）——技術哲学の**原典**に回帰
  - 原典回帰: ウィトゲンシュタイン、プラトン『国家』、カント等、Phase 1〜3で「2割理解」だったものへ
- **活動**: ブログ連載化、読書会の主催または参加、シラスでのコメント、Xでの継続的発信。年1回「自分の考えの現在地」を長文（5000字級）で書く。
- **マイルストーン（毎年更新する問い）**:
  - [ ] 「AIと人間の関係はどうあるべきか」に、借り物でない自分の立場と論拠がある
  - [ ] 技術系の友人に「哲学やってて何が変わった？」と聞かれて、具体例つきで答えられる
  - [ ] 誰かと哲学の話で**気持ちよく対立**できる（語れる、の最終形）

- **毎日**: ノートの末尾に「今日見たニュース1本 × 今週の概念」を3行で。無理にこじつけてよい（こじつけが思考の筋トレ）

- ネタ元: 普段見ているテック系ニュース（AI規制、プラットフォーム、推薦アルゴリズム、AGI論争はすべて哲学の鉱脈）

- **毎週土曜**: Claude Codeに向かって「今週の概念を3分で説明」→ Claudeが (a) 誤解の指摘 (b) より良い具体例 (c) 想定反論 を返す

- 人に話す機会（同僚とのランチ、X のリプライ）があれば常にそちらを優先

## 4. リポジトリ運用（Claude Codeコーチ）

リポジトリ構造とコマンドの正典は `docs/system-design.md`。日常で使うのは次の6つだけ:

| コマンド | いつ | 何をする |
|---|---|---|
| `/today` | 毎日（月〜金） | 復習→インプット→ニュース適用→記録まで一気通貫の30〜45分セッション。`min` で10分版、3日以上空くと復帰モード |
| `/quiz` | スキマ時間 | 復習出題だけ回す |
| `/news` | 任意 | ニュース1本×レンズの単発演習（エッセイの種づくり） |
| `/talk` | 週1任意＋月末 | ソクラテス問答／10分スピーチ練習（`speech`） |
| `/essay` | 土曜 | 週次エッセイの壁打ち→下書き保存 |
| `/review` | 日曜（週次）／月末／四半期 | 進捗集計→振り返り→シラバス調整（`week` / `month` / `quarter`） |
